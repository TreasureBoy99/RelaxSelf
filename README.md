## 🚀 安装方法

### 方式一：直接安装（推荐）

点击对应脚本文件，浏览器会提示安装。

### 方式二：手动安装

1. 安装 [Tampermonkey](https://tampermonkey.net/) 油猴扩展
2. 点击脚本文件内容，复制到 Tampermonkey 新建脚本中保存
3. 刷新页面即可生效

## 📱 兼容性

- **浏览器**：Chrome / Firefox / Edge / Safari / 国产浏览器
- **扩展**：Tampermonkey / Violentmonkey / Greasemonkey / ScriptCat
- **移动端**：Kiwi / Firefox 安卓版 + 上述油猴扩展

## ⚙️ 使用说明

1. 安装对应脚本
2. 访问目标网站
3. 广告自动屏蔽，视频正常播放
4. 部分脚本会在页面显示下载按钮或悬浮面板

## 🔧 工作原理

- 屏蔽广告元素，阻止广告脚本加载
- 捕获 / 重放 HLS (m3u8) 视频流
- 移除视频模糊遮罩（blur）和弹窗
- 部分脚本支持 AES-128 解密下载
